# Conferência de Inventário

Aplicativo Cordova da Engenharia Clínica para conferência de inventário.

## Estrutura
- `www/index.html`
- `www/style.css`
- `www/script.js`
- `www/img/icon.png`
- `www/img/splash.png`
- `resources/icon.png`
- `resources/splash.png`
- `config.xml`
- `package.json`
- `.github/workflows/gerar-apk.yml`

O GitHub Actions recria automaticamente:
- `plugins/`
- `platforms/android/`

O APK final é salvo em:
`saida/Conferencia_de_Inventario.apk`
